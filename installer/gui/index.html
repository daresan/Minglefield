Experimental encrypted database copy — explicit permission required

Diese Aktion erstellt direkt die verschlüsselte Datenbank. Vorherige Testdatenbanken und Probeprüfungen sind dafür nicht erforderlich. This action creates a REAL new encrypted SQLCipher file at the selected migration destination. It does not install Minglefield, replace the source database, authorize a Host, or activate the application. Use only controlled tests or data with a separate verified backup. Back up the original database while it is stopped; a separate filename is not automatically a valid backup. The Rust core checks the backup's contents and physical file identity before any destination publication.

Noch nicht ausgeführt: Quelle, separates Backup, Datenbankpasswort, freier Zielpfad und Zustimmung erforderlich. Zusätzliche Testkopien sind optional.
Optionale Diagnose einer früheren Migration (nur lesen)

Nach einem Abbruch kannst Du die Migration mit derselben unveränderten Quelle und dem geprüften Backup auf einen neuen, freien Zielpfad erneut starten. Die Diagnose des alten Zielpfads ist optional und für den neuen Versuch nicht erforderlich. Bestehende Zieldateien oder Belege niemals automatisch überschreiben oder löschen.

Prüft den ausgewählten Quell- und Backup-Pfad, den gespeicherten Recovery-Beleg und die verschlüsselte Zieldatei, ohne Dateien zu verändern. Dafür dieselben Datenbankpasswörter und dieselbe Auswahl der Änderungen und Schemaobjekte wie beim ursprünglichen Versuch verwenden. Ein passender Beleg beweist keine Autorisierung und erlaubt weder automatisches Fortsetzen noch Rollback oder Löschen.

Nach einem Abbruch genügt für den ersten, vorläufigen Dateistatus der bisherige Zielpfad. Diese Kurzprüfung liest nur Dateieinträge und einen eventuell vorhandenen Recovery-Beleg; sie prüft KEINE SQLCipher-Inhalte, benötigt keine Passwörter und berechtigt niemals zu einem Wiederholungsversuch.

Für die vollständige Prüfung Quelle, separates Backup, Datenbankpasswörter und genau dieselben Änderungen sowie Schema-Ergänzungen auswählen. Auch eine vollständige Übereinstimmung ist keine Wiederherstellungsfreigabe.

Noch keine Recovery-Prüfung durchgeführt. Vorhandene Belege und Zieldateien niemals automatisch löschen oder überschreiben.
Minglefield-Alpha-Anwendungsdateien installieren (separater Schritt)

Der portable Setup Manager installiert die mitgelieferte und überprüfte Python-/SQLCipher-Laufzeit samt Minglefield-Anwendung. Ein neuer, noch nicht angelegter Ordner wird automatisch erstellt. Enthält der gewählte Ordner bereits die neue verschlüsselte Datenbank, bleibt diese erhalten. Bestehende Installationen und Benutzerdaten werden niemals überschrieben. Ist in dieser Testversion kein gültiges Anwendungspaket enthalten, wird der Vorgang abgelehnt. Dies ist noch keine Host-Registrierung und kein Anwendungsstart.

Ziel ist das oben unter „Installation directory“ angezeigte Verzeichnis. Bestätige die gesonderte Schreiboperation ausdrücklich; eine Datenbankmigration oder ein Installationsplan alleine erteilt keine Freigabe.
