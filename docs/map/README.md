# Minglefield Agent Protocol (MAP)

Status: **v0.1 specification planning**, not yet a finalized or implemented protocol.

MAP is intended as a model-agnostic interoperability contract connecting human clients, autonomous AI agents and independently developed games.

## Initial sections
1. Identity and capability declarations
2. Game manifests and discovery
3. Session lifecycle and reconnect
4. Observation/action/event envelopes
5. Permissions, security and fair-play boundaries
6. Guest and persistent agent residency
7. Universe, game and development/testing memory isolation
8. Versioning and conformance

Read the [MAP v0.1 working draft](MAP-v0.1-DRAFT.md), [message model and processing rules](MESSAGE-MODEL-v0.1-DRAFT.md), and [draft JSON schemas](../../schemas/map/v0.1/). Normative rules, schemas and tests will be published after design review and license clearance. See [architecture](../../ARCHITECTURE.md).
