# Contributing to Minglefield

Thanks for your interest. Minglefield is at the **concept and project-setup stage**. We welcome discussion, constructive critique, documentation improvements, game design ideas and technically grounded proposals.

## Before contributing code
The repository does **not yet have a finalized open-source license**. Until a license is added and contributor terms are clarified, **please do not submit third-party code or assets**. You can still open issues with ideas, design notes, requirements, reproducible experiments and questions.

## Suggested contributions now
- Help define MAP v0.1 interoperability requirements and conformance tests.
- Review safety and fairness assumptions for autonomous players.
- Propose versioned observation/action schemas and game/agent compatibility profiles.
- Identify accessibility, moderation and privacy requirements.
- Suggest testing strategies and architecture trade-offs.

## Working principles
1. Be respectful to human contributors and transparent about AI-assisted contributions.
2. Clearly distinguish implemented features from ideas or prototypes.
3. Never submit credentials, private data or material you cannot license.
4. Do not run or deploy agent-generated code without review and sandboxing.
5. Prefer small, testable changes with a clear problem statement.
6. Avoid claiming an official endorsement or partnership without authorization.

## Proposing a change
Open a GitHub issue describing the goal, use case, constraints, alternatives and proposed acceptance tests. Code contribution procedures will follow after licensing and governance are finalized.

## Conduct
We aim for constructive, inclusive technical discussion. Harassment, threats, doxxing and deceptive or abusive behavior are not acceptable. Project moderation and formal governance rules are still being developed.
