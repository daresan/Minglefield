Willkommen

Dieser Setup Manager installiert die mitgelieferte Minglefield-Anwendung, übernimmt auf Wunsch eine vorhandene Datenbank, ergänzt den lokalen Administrator und startet anschließend Minglefield.

Bestehende Daten, Benutzer, Passwörter und Hostberechtigungen bleiben erhalten. Bei Migration legt der Installer intern eine unabhängige Sicherung an.

Installationsmodus

Standard verwendet die empfohlenen Speicherorte im Benutzerprofil.

Die native Minglefield-Anwendung und ihre Python-/SQLCipher-Laufzeit sind im Paket enthalten. Für die Installation sind keine Entwicklerwerkzeuge erforderlich.

Speicherorte

Bereits vorhandene Verzeichnisse sind zulässig. Vor dem Übernehmen oder Aktualisieren erscheint eine Warnung mit „Weiter“ oder „Abbruch“. Bisherige Programmdateien werden vor einem Austausch gesichert.

Datenbank

Optional eine bisherige Alpha-Datenbank auswählen. Ohne Quelle wird eine neue verschlüsselte Datenbank angelegt. Eine bereits gültige verschlüsselte Zieldatenbank wird unverändert übernommen.

Suche im Minglefield-Datenordner …

Migration und Verschlüsselungsprüfung erfolgen intern erst während der Installation. Keine zusätzlichen Prüfaktionen oder Passworteingaben auf der letzten Seite.

Datenbank bearbeiten, Schema prüfen und lokalen Administrator einrichten

Die auf Seite 4 gewählte Datenbank wird mit ihrem Passwort schreibgeschützt geöffnet. Du kannst vorhandene Datensätze ansehen und Änderungen für die spätere Migration vormerken. Die Quelldatenbank bleibt unverändert. Dies ist keine Testmigration.

Noch keine Datenbank geöffnet. Ohne Quelldatenbank wird eine neue verschlüsselte Datenbank erstellt.

Schemaüberprüfung und optionale Schemamigration

Noch kein Schema gelesen.

Fehlende registrierte Schemaobjekte werden nach dem Entsperren der Datenbank angezeigt.

Die Ergänzungen werden nur bei der tatsächlichen Installation auf einer neuen verschlüsselten Zielkopie ausgeführt. Keine Änderung an der Quelle, kein vorgeschalteter Schreibtest.

Lokalen Host-Administrator mingleadmin einrichten

Hostzuordnungen werden aus der entsperrten Datenbank angezeigt. Bestehende Host-IDs bleiben erhalten; bitte keinen Remote-Host auswählen.

Falls mingleadmin bereits existiert, bleiben sein Passwort und seine bestehenden Rechte erhalten; dann können die beiden Passwortfelder leer bleiben. Ansonsten ein separates Passwort mit mindestens zwölf Zeichen wählen. Andere User und Host-Administratoren bleiben unverändert, es entstehen keine Remote-Host-Rechte.
